# Русская озвучка

[Все модули](../../README.md)

Подмена отдельных штатных реплик TSpeech подготовленными записями голосом Алисы. Модуль сопоставляет известные фразы с русскими клипами.

Идентификатор пакета: `io.github.luckdmst.q05.alicevoice`.

## Скачать

[APK code10](https://github.com/LuckDMST/qiyuan-q05-mods/releases/download/alice-voice-code10/qiyuan-q05-alice-voice-code10.apk) · [Описание выпуска](https://github.com/LuckDMST/qiyuan-q05-mods/releases/tag/alice-voice-code10)

SHA256: `9A90E8630E3624570B5AE8F04E56F69F64FBA4D12FA86D0E9BD7263D9F076B41`.

## Что проверили

Заменяет поддерживаемые выходные фразы записью голоса Алисы. Установка code10, загрузка модуля и готовность трёх коротких PCM подтверждены на B216. Живые голосовые итоги всех сценариев ещё не проверены.

## Использование

Этот APK предназначен для ГУ B216 с уже настроенным LSPosed. В LSPosed укажите только TSpeech (com.tinnove.wecarspeech). Модуль меняет озвучку поддерживаемых фраз. Проверяйте работу на стоянке.

[Наружная озвучка зарядки](exterior-charge-voice.md) и [голосовой ввод Dicio](dicio-voice-input.md) ведутся отдельно.
