# Перевод предупреждения кругового обзора

[Все модули](../../README.md)

Этот модуль меняет текст предупреждения кругового обзора AVM, которое появляется при открытом багажнике. Он рассчитан на устройства с Magisk.

## Состояние проекта

Подготовлен ZIP с русским текстом. На B216 проверили хеш временно изменённого файла настройки, но новый пакет Magisk и русское предупреждение на экране ещё не проверяли. Публичной сборки для установки пока нет.

## Что делать сейчас

Пока готового пакета для установки нет. Дождитесь проверенного выпуска и инструкции к нему.
