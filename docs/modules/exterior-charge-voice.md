# Русские реплики внешнего громкоговорителя

[Все модули](../../README.md) · [Озвучка Алисы в TSpeech](russian-voice.md)

Здесь можно прослушать четыре русские реплики, которые произносит внешний громкоговоритель автомобиля во время зарядки. Это наши записи для машины. Они не извлечены из стороннего APK.

## Прослушать

| Событие | Реплика | Запись | Проверка |
| --- | --- | --- | --- |
| Кабель подключён | Кабель подключён. Всё готово к зарядке. | [Прослушать WAV](../../samples/exterior-charge/36_1.wav) | Файл загружен службой, звучание отдельно не подтверждено |
| Зарядка завершена | Зарядка завершена. Отсоедините кабель. | [Прослушать WAV](../../samples/exterior-charge/36_2.wav) | Файл загружен службой, звучание отдельно не подтверждено |
| Зарядка прервана | Зарядка прервана. | [Прослушать WAV](../../samples/exterior-charge/36_3.wav) | Звучание подтверждено |
| Зарядка началась | Зарядка началась. | [Прослушать WAV](../../samples/exterior-charge/36_4.wav) | Звучание подтверждено |

Записи относятся к системному сервису WTAudio на Linux приборки. Это отдельный механизм, он не устанавливается через Android-модуль Alice Voice. Файлы профиля `0x0077` совпадают по SHA-256 с установленными в машине.

## Формат

PCM WAV, стерео, 48 кГц, 24 бита. В репозитории опубликованы русские записи. Оригинальные файлы стороннего APK сюда не включены.
