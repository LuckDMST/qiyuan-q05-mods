# Русский интерфейс нативной приборки

[Все модули](../../README.md)

Русские подписи и предупреждения водительской панели, а также правки разметки для нативного Linux HMI приборки.

## Скачать и установить

- [Скачать установщик Windows x64](https://github.com/LuckDMST/qiyuan-q05-mods/releases/download/cluster-native-ru-2026-11-21_04/Qiyuan-Q05-B216-Cluster-RU-Windows.zip). Распакуйте ZIP и запустите `Start.cmd`.
- [Описание выпуска](https://github.com/LuckDMST/qiyuan-q05-mods/releases/tag/cluster-native-ru-2026-11-21_04).
- [Архив ресурсов Linux HMI для ручной установки](https://github.com/LuckDMST/qiyuan-q05-mods/releases/tag/cluster-native-ru-2026-11-16_14).

Поддерживаемая сборка головного устройства B216 — `SWC.1371.RB216000004`.

## Как установить

1. Остановите автомобиль в P и подключите головное устройство к Windows по USB.
2. Распакуйте ZIP в папку с правом записи. В архиве уже есть Python, ADB и OpenSSH.
3. Откройте `Start.cmd` и выберите **1. Проверить состояние приборки**.
4. Если проверка прошла, выберите **2. Установить русский перевод**. Перед заменой установщик проверит или создаст заводскую копию.
5. Для восстановления используйте пункт **3**. Пункт **4** проверяет или создаёт заводскую копию.

Установщик рассчитан на B216 со сборкой ГУ `SWC.1371.RB216000004`. Root на Android не нужен. Для записи ресурсов требуется root-доступ к Linux T-Box. Установщик не перезагружает автомобиль или ГУ.

Сам установщик проверен на B216 и запускался в Windows с пустым `PATH`. Автоматический вход проверен с имитацией подключения. Тест с чистой Windows и физическим автомобилем отдельно не проводился.
