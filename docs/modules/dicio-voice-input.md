# Русский голосовой ввод (Dicio / Vosk)

[Все модули](../../README.md)

Эксперимент с распознаванием речи на русском через Dicio и Vosk. Цель — показать распознанную команду в штатном окне и передать её обработчику автомобиля.

Состояние на 21 ноября 2026 года. Проверки проводились на Qiyuan Q05 LU+ с ГУ B216.

## Что проверили на машине

APK code7 установлен для эксперимента. Модуль LSPosed выключен.

## Что в работе

Исследуем передачу микрофона, распознавание русского в штатном окне и выполнение команд автомобиля. Сценарий от кнопки микрофона до выполнения команды пока не подтверждён.
