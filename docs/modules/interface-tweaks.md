# Интерфейс и настройки

[Все модули](../../README.md)

Доработки центрального экрана. В модуле есть плитки Android Settings и разделения экрана, раздвижная полоса между окнами, изменения лаунчера, плашек и клавиатуры.

Идентификатор пакета: `io.github.luckdmst.q05.interface`.

## Что проверили

На B216 проверены открытие редактора приложений второго окна и сохранение отметок. Разделение экрана и скрытие рекомендаций проверялись в предыдущих сборках. Остальные изменения этого выпуска требуют отдельных проверок.

## Использование

Этот APK предназначен для ГУ B216 с уже настроенным LSPosed. Для второго окна используйте плитку модуля или пункт «Приложения для второго окна» в Q05 Сервисе. Область действия LSPosed: com.tinnove.scenemode, com.android.systemui, com.tinnove.aiassistant, com.wt.cardesktop3d, com.tinnove.launcher. Проверяйте работу на стоянке.
