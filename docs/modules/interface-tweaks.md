# Интерфейс и настройки

[Все модули](../../README.md)

Модуль добавляет настройки интерфейса центрального экрана: плитки Android Settings и второго окна, разделение экрана и ползунок между окнами, а также изменения лаунчера, плашек и клавиатуры.

## Что понадобится

- ГУ B216 с настроенным LSPosed.
- Q05 Сервис, если хотите открыть список приложений для второго окна из его меню.

## Установка и использование

1. Установите APK и включите модуль в LSPosed для приложений, перечисленных ниже.
2. Перезапустите затронутые приложения.
3. Для настройки второго окна откройте плитку модуля или пункт «Приложения для второго окна» в Q05 Сервисе.
4. Проверяйте изменения на стоянке.

Область LSPosed для этого выпуска: `com.tinnove.scenemode`, `com.android.systemui`, `com.tinnove.aiassistant`, `com.wt.cardesktop3d`, `com.tinnove.launcher`.

На B216 проверено открытие редактора приложений второго окна и сохранение выбранных отметок. Разделение экрана и скрытие рекомендаций проверялись в предыдущих выпусках. Остальные изменения code52 требуют проверки.
